1 Comprendre : Skill, Agent, quelle différence ?

Avant d'écrire la moindre ligne, comprendre précisément ce qu'on construit. Deux concepts clés, deux rôles distincts.

🧩

Le Skill (compétence)

Un fichier texte structuré (SKILL.md) qui explique à Claude comment faire une tâche précise. Il décrit la méthode, le vocabulaire, les formats de sortie. Claude le lit avant d'agir. C'est comme donner un manuel de procédures à un collègue.

🤖

L'Agent (assistant configuré)

Un Claude.ai "personnalisé" via un system prompt dans un Projet. L'agent a un rôle défini, un ton, un périmètre d'action. Il peut utiliser des skills. C'est comme recruter un assistant avec une fiche de poste précise.

🔗

Skill + Agent = outil complet

Le skill apporte le savoir-faire (comment rédiger une fiche séance). L'agent apporte le rôle et le cadre (qui il est, pour qui il travaille, dans quel style). Ensemble, ils forment un outil spécialisé prêt à l'emploi.

💡

Analogie pédagogique : Un skill, c'est comme la fiche de poste d'un animateur. L'agent, c'est l'animateur lui-même. La fiche lui dit comment travailler. Lui sait avec qui et dans quel cadre.

2 Construire : le skill et l'agent animateur jeunesse

On construit deux choses : le fichier SKILL.md (la méthode) et le system prompt de l'agent (le rôle). Voici les deux codes complets, commentés.

2.1 Le SKILL.md complet (à copier, adapter, installer)

SKILL.md 
---
name: doc-animateur-jeunesse
description: >
  Génère des documents professionnels pour les animateurs jeunesse et
  structures d'animation (ACM, centres sociaux, MJC, ALSH, collectivités,
  BAFA/BAFD). Utilise ce skill dès que la demande porte sur : fiche séance,
  projet d'animation, compte-rendu de réunion, rapport d'activité, bilan
  BAFA ou BAFD, projet pédagogique, fiche d'évaluation, note partenariale,
  planning d'animation, fiche incident.
---

# Skill : Documents animateur jeunesse

## 1. Identifier le document demandé

Poser les questions si elles manquent :
- Type de structure (ACM, MJC, centre social...)
- Tranche d'âge du public
- Thème ou intitulé de l'activité
- Période concernée
- Destinataire du document

## 2. Types de documents et structures types

### A. Fiche séance / Projet d'activité
Structure : Titre / Objectifs (2-4 verbes d'action) / Public / Durée /
Matériel / Déroulement (accueil > mise en activité > temps fort > bilan) /
Évaluation / Animateur(s) référent(s)

### B. Compte-rendu de réunion
Structure : Date, lieu, participants / Ordre du jour / Points abordés /
Décisions / Actions (Qui / Quoi / Quand) / Prochaine réunion

### C. Bilan de stage BAFA / BAFD
4 axes obligatoires :
1. Vivre en collectivité
2. Animer et mettre en oeuvre un projet
3. Assurer la sécurité physique, morale, affective
4. Participer au fonctionnement de l'équipe

## 3. Vocabulaire professionnel
ACM, ALSH, DDETS, BAFA, BAFD, projet pédagogique, taux d'encadrement
(1/8 pour moins de 6 ans, 1/12 pour plus de 6 ans), CRIP, IP

## 4. Format de sortie
- Markdown structuré par défaut
- Jamais plus de 2 pages pour une fiche séance
- Dater et signer tout document transmis à l'extérieur
📝

Règle d'or : La description dans le frontmatter est le déclencheur automatique. Plus elle est précise et riche en mots-clés métier, plus Claude l'activera au bon moment. C'est votre "interrupteur" intelligent.

2.2 Le system prompt de l'agent (à coller dans un Projet Claude.ai)

System Prompt - Agent 
# Agent IA - Assistant Rédaction Animateur Jeunesse

Tu es un assistant spécialisé pour les animateurs et directeurs de structures
jeunesse en France.

## Ton rôle
Tu aides à rédiger : fiches séance, projets d'animation, comptes-rendus,
rapports d'activité, bilans BAFA/BAFD, projets pédagogiques, notes
partenariales, fiches incident.

## Ton style
- Ton chaleureux, professionnel, encourageant
- Langage clair, sans jargon inutile
- Si tu utilises un terme technique (DDETS, CRIP...), explique-le

## Comment tu travailles
1. Identifie le type de document demandé
2. Si des informations manquent, pose 2 ou 3 questions ciblées AVANT de rédiger
3. Génère le document structuré, prêt à copier-coller
4. Propose une liste "points à vérifier avant diffusion" en fin de document

## Ce que tu NE fais PAS
- Tu ne rédiges pas de signalement officiel (IP, CRIP) seul
- Tu ne fournis pas de conseils médicaux ou juridiques
- Tu ne génères pas de données personnelles fictives sur de vrais enfants

## Cadre légal
- Code de l'action sociale et des familles (CASF)
- Arrêté du 9 février 2007 (encadrement des mineurs)
- Référentiel BAFA/BAFD (DJEPVA)
- RGPD pour les données nominatives

2.3 Où installer le skill et configurer l'agent

📁

Installation du skill

Dans Claude.ai : Menu "Skills" (onglet en haut à gauche) > "Ajouter un skill" > Glisser-déposer le fichier .skill ou coller le SKILL.md.

🗂️

Configuration de l'agent

Dans Claude.ai : Créer un nouveau "Projet" > Coller le system prompt dans le champ "Instructions du projet". Le projet mémorise le contexte entre les sessions.

🔒

Portée et partage

Un Projet peut être partagé avec une équipe (Claude Pro ou Teams). Le skill reste personnel sauf export du fichier .skill que vous donnez aux collègues.

3 Tester : mise en pratique et correction

Trois exercices progressifs à réaliser dans Claude.ai. Pour chacun, comparez le résultat obtenu à la grille d'évaluation fournie.

Exercice 1 - Niveau débutant

La fiche séance clé en mains

Copiez ce prompt dans votre agent ou dans Claude avec le skill activé :

"Je dois rédiger une fiche séance sur le recyclage pour des enfants de 8 à 12 ans. Durée : 1h30. Je travaille en ALSH, groupe de 16 enfants, 2 animateurs."
Ce que vous devez obtenir :
- Titre clair et intitulé professionnel
- 2 à 4 objectifs avec des verbes d'action (identifier, distinguer, fabriquer...)
- Liste matériel concrète
- Déroulement en 3 ou 4 phases avec durées
- Une modalité d'évaluation simple (question aux enfants, observation...)
Exercice 2 - Niveau intermédiaire

Le compte-rendu de réunion à partir de notes brutes

Copiez ce prompt :

"Réunion équipe lundi 19 mai, 14h, salle polyvalente. Présents : Marie (directrice), Karim, Léa, Tom. Excusé : Sacha. On a parlé de la rentrée septembre - faut acheter du matériel, Karim s'en occupe avant le 30 juin. Aussi la journée cohésion prévue le 5 juillet, Léa prépare le programme d'ici vendredi. On se revoit le 9 juin."
Ce que vous devez obtenir :
- En-tête structuré (date, lieu, présents, excusés)
- Points de l'ordre du jour identifiés
- Décisions claires et distinctes des discussions
- Tableau ou liste Qui / Quoi / Quand pour les actions
- Prochaine réunion notée
Exercice 3 - Niveau avancé

Le bilan BAFA guidé

Copiez ce prompt (simulez un stagiaire) :

"J'ai fait mon stage pratique BAFA de 3 semaines dans un centre de vacances ados (14-17 ans) au bord de mer en Bretagne. J'ai encadré des activités sports nautiques et soirées. Un soir il y a eu un conflit entre deux ados. Je cherche comment structurer mon bilan."
Ce que vous devez obtenir :
- Questions complémentaires avant de rédiger (noms et dates fictifs, nombre de jeunes, équipe...)
- Ensuite : bilan structuré sur les 4 axes BAFA nommés
- La situation du conflit utilisée comme "situation significative" analysée
- Auto-évaluation proposée (points forts + axes de progression)
- Pas de données personnelles réelles générées

Grille de correction et validation qualité

  • ✓
    Le skill se déclenche sans qu'on le demande explicitement Test : écrivez "fiche séance recyclage 8-12 ans" sans mentionner le skill. Claude doit l'utiliser automatiquement.
  • ✓
    Le vocabulaire professionnel est correct et cohérent Vérifier : ACM, ALSH, BAFA, taux d'encadrement sont utilisés à bon escient.
  • ✓
    L'agent pose des questions avant de rédiger si le contexte est vague Test : écrivez juste "aide-moi à faire un bilan". Il doit vous questionner, pas improviser.
  • ✓
    Le format de sortie est utilisable directement Le document doit être copiable en Word ou Google Docs sans reformatage lourd.
  • ✓
    Les limites légales sont respectées Pour une fiche incident, l'agent ne rédige pas de signalement officiel seul. Il guide, oriente.
  • ✓
    Le ton est adapté au public (animateurs, directeurs) Ni trop académique, ni trop familier. Professionnel mais humain.
⚠️

Erreur fréquente : Le skill ne se déclenche pas. Cause principale : la description dans le frontmatter est trop courte ou trop générique. Solution : ajouter des mots-clés métier et des formulations concrètes que les utilisateurs emploient réellement ("fiche séance", "bilan BAFA", "je dois rédiger pour mon ACM"...).

Que faire si le résultat est décevant ?

Problème constatéCause probableCorrection dans le SKILL.md
Document trop générique Vocabulaire métier manquant Enrichir la section "Vocabulaire professionnel"
Structure incomplète Template pas assez détaillé Ajouter des exemples de sections dans chaque type de document
L'agent ne pose pas de questions System prompt insuffisant Renforcer l'instruction "poser 2-3 questions si contexte vague"
Ton trop formel Style non défini Ajouter "Ton chaleureux, professionnel, humain" dans le system prompt
Dates ou noms inventés Données manquantes Instruction "ne jamais inventer données nominatives, demander à l'utilisateur"

4 Déployer : mise en production dès demain

Un plan d'action heure par heure pour que l'outil soit opérationnel dans votre structure le lendemain matin.

Étape 1
30 min

Télécharger les fichiers et créer votre compte Claude Pro (si pas encore fait)

Récupérer les 3 fichiers livrés avec ce tutoriel : SKILL.md, agent-system-prompt.md, doc-animateur-jeunesse.skill. Ouvrir Claude.ai - un compte gratuit suffit pour démarrer.

Étape 2
15 min

Créer le Projet "Animateur Jeunesse" dans Claude.ai

Menu gauche > "Projets" > "Nouveau projet". Nommer : "Assistant Rédaction Jeunesse". Coller le contenu de agent-system-prompt.md dans le champ "Instructions".

Étape 3
10 min

Installer le skill

Dans Claude.ai > "Skills" > "Ajouter un skill" > Glisser doc-animateur-jeunesse.skill. Vérifier que le skill apparaît dans la liste avec le bon nom.

Étape 4
20 min

Tester les 3 exercices du chapitre précédent

Directement dans le nouveau Projet. Comparer les sorties à la grille de correction. Ajuster le SKILL.md si besoin (modifier le fichier texte et réinstaller).

Étape 5
15 min

Former un collègue animateur ou directeur

Montrer l'outil en 10 minutes. Partager le lien du Projet (si Claude Teams) ou donner le fichier .skill à installer sur leur propre compte. Ce tutoriel HTML sert de documentation.

Semaine 1

Recueillir les retours et première itération

Demander aux animateurs : "Qu'est-ce qui n'était pas assez précis ? Quel type de document vous manque ?" Ouvrir le SKILL.md, ajouter les ajustements, réinstaller. Le cycle d'amélioration prend 15 minutes par itération.

🚀

Aller plus loin : Une fois le premier skill maîtrisé, vous pouvez créer un second skill eval-formation-jeunesse.skill pour générer les outils d'évaluation Qualiopi (feuilles d'émargement, questionnaires de satisfaction, attestations). La méthode est identique.

Checklist "prêt à déployer"

  • Le fichier SKILL.md est sauvegardé dans un dossier partagé (Drive, Nextcloud, Notion)
  • Le skill est installé et visible dans Claude.ai
  • Le Projet est créé avec le system prompt complet
  • Les 3 exercices ont été testés et les résultats sont satisfaisants
  • Au moins un collègue a été formé en 10 minutes
  • Une procédure simple d'amélioration est notée (modifier > réinstaller)
  • Le cadre RGPD est respecté : aucune donnée nominative réelle stockée dans le Projet

G Glossaire des termes complexes

15 concepts clés, définis simplement. Pour les animateurs qui découvrent l'IA, les formateurs qui veulent expliquer, et les curieux qui passent par là.

Skill (compétence IA) IA
Fichier texte structuré (SKILL.md) qui donne à Claude une "expertise" précise sur un domaine. Il décrit les méthodes, vocabulaires et formats à utiliser. Claude le lit avant de répondre.
Ex : un skill "animateur jeunesse" = Claude sait rédiger une fiche séance BAFA sans que vous expliquiez ce que c'est.
Agent IA IA
Un modèle d'IA configuré pour un rôle précis via un "system prompt". L'agent a une identité, un périmètre d'action, un style. Contrairement à un ChatGPT générique, il est spécialisé.
Ex : "Assistant Rédaction Jeunesse" qui sait qui il est, ce qu'il fait, et ce qu'il ne fait pas.
System Prompt IA
Instructions données à Claude AVANT la conversation, invisibles pour l'utilisateur final. Elles définissent le rôle, le ton, les règles et les limites de l'agent. C'est la "fiche de poste" de l'IA.
Ex : "Tu es un assistant pour animateurs. Tu poses des questions avant de rédiger..."
LLM IA
Large Language Model (Grand Modèle de Langage). Système d'IA entraîné sur des milliards de textes, capable de comprendre et générer du texte. Claude, GPT-4, Gemini sont des LLM.
Le LLM est le moteur. Le skill et le system prompt sont le volant et le tableau de bord.
Frontmatter Technique
Bloc de métadonnées en tête d'un fichier Markdown, délimité par "---". Il contient le nom, la description et d'autres paramètres lus en priorité par le système.
C'est l'équivalent de la couverture d'un livre : titre, auteur, sujet. Claude lit ça en premier.
Markdown (.md) Technique
Format de texte simple où la mise en forme s'écrit en caractères (# pour titre, ** pour gras, - pour liste). Lisible sans logiciel spécial, convertible en Word ou HTML facilement.
## Titre = titre de niveau 2. - élément = point de liste. C'est tout.
Token IA
Unité de traitement du texte par un LLM. Environ 3/4 d'un mot en français. Les modèles ont une limite de tokens par conversation (fenêtre de contexte). Quand la limite est atteinte, le modèle "oublie" le début.
Un skill de 500 lignes = environ 8 000 tokens. Une fiche séance = 500 à 1 000 tokens.
Prompt IA
La question ou instruction que vous écrivez à l'IA. Un bon prompt est précis, contextualisé, et indique le format de réponse attendu. C'est la compétence principale à développer.
Mauvais : "fais une fiche". Bon : "fiche séance recyclage, 8-12 ans, 1h30, ALSH, 16 enfants, 2 animateurs".
Hallucination IA
Quand un LLM invente des informations fausses avec assurance. Risque réel sur les données légales (taux d'encadrement, dates de décrets...). Toujours vérifier les informations juridiques.
Claude peut citer un article de loi inexistant. Le skill réduit ce risque en fournissant les vraies références.
Projet Claude.ai Outil
Espace de travail dans Claude.ai qui mémorise un contexte entre les sessions, peut contenir un system prompt, des fichiers de référence et être partagé avec une équipe.
Le Projet "Animateur Jeunesse" = votre agent spécialisé accessible à toute l'équipe.
ACM Jeunesse
Accueil Collectif de Mineurs. Désigne toute structure organisant des activités pour mineurs (ALSH, séjours, accueil périscolaire). Soumis à déclaration obligatoire à la DDETS.
ALSH Jeunesse
Accueil de Loisirs Sans Hébergement. Ce que le grand public appelle "centre de loisirs" ou "centre aéré". Accueil en dehors du temps scolaire (mercredis, petites vacances, été).
DDETS Jeunesse
Direction Départementale de l'Emploi, du Travail et des Solidarités. Tutelle administrative des ACM. Reçoit les déclarations de séjours, contrôle l'encadrement, gère les agréments BAFA/BAFD.
CRIP Jeunesse
Cellule de Recueil des Informations Préoccupantes. Service du Conseil Départemental à contacter en cas de doute sur la sécurité d'un enfant. L'agent IA ne peut pas faire ce signalement à votre place.
RGPD Légal
Règlement Général sur la Protection des Données (UE, 2018). Encadre la collecte et le traitement de données personnelles. Ne jamais saisir de vraies données nominatives d'enfants dans un outil IA tiers.
En pratique : utilisez "l'enfant X" ou des pseudonymes dans vos documents générés par IA.
